# 前端样式与交互说明

本次调整保留现有接口、路由、store、composable 和业务处理函数。修改集中在 CSS、少量展示文案、组件的布局属性及按钮语义；修改的 Vue 文件中，`<script>` 内容均保持不变。

当前版本采用「深夜唱片室」风格：暖黑背景、米白文字、铜橙强调色。首页重新编排为介绍文案、唱片插画和功能介绍；品牌文字可返回首页，新增的首页入口使用 `router-link` 连接已有歌曲库、歌单路由。没有增加依赖或修改接口、搜索、播放、登录流程。

## 1. 使用了哪些库

- **Element Plus**：继续使用项目已有组件，没有新增组件库或依赖。
- **@element-plus/icons-vue**：继续使用已有的播放、列表、导航、头像等图标。
- **Vue 内建组件**：保留 `Transition`、`Teleport`，没有另外引入动画库。
- **vue-draggable-plus**：继续承接原来的队列拖拽，本次只调整周边样式。
- **普通 CSS**：布局、颜色、悬浮反馈和响应式由 CSS 实现。本次没有新增 Tailwind 工具类，原有 Tailwind 依赖继续保留。

## 2. 组件怎么用

| 位置 | 组件 | 本项目的用法与调整 |
|---|---|---|
| 主布局 | `el-container`、`el-aside`、`el-main` | 保留左侧导航和右侧内容结构，修正滚动、内容最小高度与播放器占位 |
| 侧栏导航 | `el-menu`、`el-menu-item` | 原来的 `router` 与 `default-active` 保留；仅美化 `.is-active` 的背景、左侧标记与图标 |
| 用户菜单 | `el-dropdown`、`el-dropdown-menu` | 原来的命令处理不变；统一浮层圆角、菜单悬浮背景 |
| 搜索 | `el-input` | 原来的 `v-model`、清空与搜索事件不变；调整 wrapper 高度、边框和聚焦光晕 |
| 歌曲列表 | `el-table`、`el-table-column` | 保留数据和双击播放事件；设置明确的最小列宽，操作列 `fixed="right"`，窄屏可横向滚动 |
| 空状态 | `el-empty` | 新增在歌曲表格的 `#empty` 插槽中，仅负责无数据时的呈现 |
| 播放队列 | `el-drawer`、`el-segmented` | 保留 `v-model`、右侧展开及页签切换；统一抽屉背景，限制宽度不超过视口 |
| 分页 | `el-pagination` | 保留页码、每页条数及事件；修正作用域选择器和颜色，窄屏缩小间距、允许换行 |
| 提示与按钮 | `el-tooltip`、`el-button`、`el-icon` | 保留原功能，统一主色、悬浮和禁用状态；补足歌曲操作按钮的键盘焦点 |
| 用户信息 | `el-avatar` | 保留头像数据和文字回退；调整个人中心横幅、卡片和头像外框 |

歌曲表格的展示属性示例：

```vue
<el-table-column label="标题" min-width="220" show-overflow-tooltip />
<el-table-column label="操作" width="116" fixed="right" />
<template #empty>
  <el-empty description="暂时没有歌曲" :image-size="64" />
</template>
```

`min-width` 给内容保留可读空间，`fixed="right"` 让操作列在横向滚动时仍可见。官方参考：[Table](https://element-plus.org/en-US/component/table.html)。

**创建歌单的弹窗仍是自定义 HTML + CSS，不是 `el-dialog`。** 登录页的输入框和按钮也是原生元素。没有为了统一外观而替换它们的表单实现。

## 3. 统一主题怎么实现

全局主题放在 `web/src/assets/main.css`：

```css
html:root {
  color-scheme: dark;
  --music-primary: #dba272;
  --music-primary-soft: #34291f;
  --music-on-primary: #21170f;
  --music-text: #eee8df;
  --music-border: #36312c;
  --music-surface: #201e1b;
  --music-canvas: #171615;
  --el-color-primary: var(--music-primary);
}
```

`--music-*` 供自定义组件使用，`--el-*` 供 Element Plus 使用。这样分页、播放器和普通按钮可以使用相同主色。`html:root` 的选择器优先级略高于库的 `:root`，避免按需加载组件样式后覆盖主题。

深色主题还统一了 Element Plus 的文字、填充、禁用态、边框、表格、空状态插画和加载遮罩，避免弹窗或下拉菜单仍是浅色。铜橙色实心按钮使用 `--music-on-primary` 的深色文字，以保证对比度。颜色值集中管理，布局规则仍在组件内。

组件专属布局继续放在各自 `<style scoped>` 中。修改 Element Plus 内部节点使用 `:deep(...)`；根元素自己的类直接写 `.app-pagination`，不再用要求额外祖先层级的选择器。

通过 `Teleport` 到 body 的公共浮层外观放在全局，例如队列抽屉 body 的内边距。这样不会因浮层脱离原 DOM 层级而失效。

## 4. 交互效果怎么做到

### 悬浮、按下与聚焦

- 卡片：`:hover` 配合 `translateY`、边框与阴影，做轻微上浮。
- 播放按钮：悬浮略微上移，`:active` 缩小，提供按下反馈。
- 搜索框：Element Plus 自动切换 `.is-focus`，CSS 根据它显示焦点光晕。
- 键盘操作：`:focus-visible` 显示焦点框；歌曲操作由可点击图标改为原生 `button`，继续调用原来的 emit，Enter/空格触发由浏览器提供。
- 触屏：`@media (hover: none)` 让表格操作和队列手柄常显，避免依赖鼠标悬浮。

这些效果没有新增业务状态或计时器。

### 本版的唱片视觉与列表交互

- 首页封套由普通 `div`、文字、圆形边框与轻微旋转构成；黑胶纹理由 `repeating-radial-gradient` 绘制，没有图片请求、Canvas 或动画依赖。装饰区域设置 `aria-hidden="true"`。
- 歌单卡片使用原有 `router-link`，悬停或键盘聚焦时出现 `::after` 箭头，表示查看歌单；它不是新增播放按钮。歌曲数量直接展示已有 `song_count`。
- 歌曲表格的按钮在行悬停或 `.song-table__action-bar:focus-within` 时显现。触屏用 `@media (hover: none)` 常显，原来的播放事件与双击事件保持不变。
- 进度条的可操作容器仍有 24px 高，视觉轨道平时 3px、悬停 5px；保留原有 `range` 输入与事件。
- 折叠侧栏同时将 `.el-menu-tooltip__trigger` 的内边距清零并居中，避免 Element Plus 默认 20px 内边距使图标偏右。
- 歌词用字号、亮度与留白区分当前行，唱片仍按原来的 `is-playing` 暂停或旋转；减少动态效果时停止唱片动画。

### 登录、注册切换与歌曲详情展开

这两类交互本来就使用 Vue `Transition`。本次保留原来的条件和路由，只调整周边外观。`Transition name="auth-form"` 对应 `.auth-form-enter-*`、`.auth-form-leave-*`，CSS 的透明度和 Y 轴旋转负责表单过渡；歌曲详情继续使用 `slide-up` 的垂直位移。官方参考：[Transition](https://vuejs.org/guide/built-ins/transition.html)。

### 队列抽屉与拖拽

`el-drawer` 继续通过原来的 `isQueueVisible` 控制开关，`el-segmented` 继续切换当前队列/队列列表。`VueDraggable` 原来的 `handle=".drag-handle"`、`ghost-class="drag-ghost"`、动画参数和更新流程均保留。新样式只改善抽屉边界、选中行、拖拽手柄与占位颜色。官方参考：[Drawer](https://element-plus.org/en-US/component/drawer.html)。

### 进度条与音量条

继续使用原来的原生 `input type="range"` 和绑定：进度条的底轨、缓冲、已播放部分由不同 CSS 层绘制。滑块在悬浮或键盘聚焦时显现；补充 Firefox 的 `::-moz-range-thumb` 样式。没有改动拖动、松手提交或音量更新逻辑。

### 自定义弹窗与响应式

- 创建歌单弹窗用 CSS `@keyframes` 做短暂的淡入和轻微位移；没有新增开关逻辑。
- 用 `max-height: calc(100dvh - 40px)` 与内部滚动，避免小屏弹窗超出可视范围。
- 600px 以下，侧栏用 CSS 收成图标导航，不修改 `isCollapse`；保留 `aria-label` 供辅助技术识别。
- 768px 以下，播放器使用两行 CSS Grid：歌曲信息和音量在第一行，播放控制在第二行，不修改播放状态。
- 系统启用“减少动态效果”时，通过 `prefers-reduced-motion` 缩短新增动画与过渡；队列音柱使用静态显示。

## 3. 简历上优先提炼什么

建议项目名称：全栈音乐播放器。

当前主要技术栈：Vue3、TypeScript、Pinia、Spring Boot、MyBatis-Plus、MySQL、Redis、JWT、Flyway、Nginx、Docker Compose。Swagger 和测试工具可以放在职责内容中。Flask、SQLite、Node.js/Express 作为演进经历，不必挤入当前技术栈。

简历素材草案（根据个人实际参与和理解程度取舍）：

1. 持续迭代前后端分离音乐播放器，完成用户认证、歌曲上传管理、歌单、播放队列、播放状态保存及滚动歌词等功能，并新增播放历史链路。
2. 将 Flask 原型经 Node.js 过渡迁移至 Spring Boot，按业务模块整理后端结构；拆分前端播放器状态与 composables，统一接口类型和异常处理。
3. 基于 JWT 与 Redis 实现登出令牌失效管理，补充资源归属校验、登录限流和上传文件校验；为部分业务查询配置缓存及失效处理。
4. 使用 Flyway 管理数据库版本，引入关系与唯一性约束，处理队列排序和重复数据问题；统一 bigint/Long/字符串 ID 契约，避免前端精度丢失。
5. 使用 Docker Compose 编排应用与数据服务，通过 Nginx 托管前端、代理 API 和提供静态资源，并补充前后端单元测试及数据库迁移测试。

简历通常保留其中 3—4 条，按目标岗位排序。以上是项目事实素材，不自动等价于全部由本人独立设计实现；AI 辅助部分应能解释设计、修改和验证过程。

| 主题 | 仓库证据 | 需要自己讲清楚 |
